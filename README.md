# 🔄 Recursion Repository

Welcome to my **Recursion** repository! This repository contains a collection of recursion problems implemented primarily in **Java**. It is designed to help beginners build a strong foundation in recursion and gradually progress to advanced recursive problem-solving techniques used in coding interviews.

---

# 📖 About

Recursion is a programming technique in which a function calls itself to solve smaller instances of the same problem. It is one of the most important concepts in Data Structures and Algorithms and forms the basis for techniques such as Backtracking, Divide & Conquer, and Dynamic Programming.

This repository includes:

* ✅ Beginner-friendly recursion problems
* ✅ Classic interview questions
* ✅ Pattern-based recursion problems
* ✅ Well-commented Java solutions
* ✅ Time and Space Complexity analysis
